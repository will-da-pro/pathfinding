**Date:** 17–20 Jun 2026

**What I worked on:** One small navigation tweak in `line_follow`. In `pathfinding`, added tracking of nodes between frames: a Hungarian-algorithm assignment (via a new `extern/hungarian-algorithm-cpp` submodule) matches newly observed nodes to previously tracked ones, wrapped in a `TrackedNode` (with a `cv::KalmanFilter` per node, `age`/`missedFrames` counters) and `TrackedGraph`. Built a cost matrix from position distance plus a penalty for differing connected-edge counts, solved it, and used the result to update matched nodes and add/prune unmatched or stale ones.

**Reflection:** The cost-matrix function had a real bug from the day it was written, it stored the penalty term instead of the combined distance-plus-penalty cost (`costs[i][j] = penalty;` instead of `= cost;`), which wasn't caught for about a month. Shows how bugs can last for a while in production before being caught.

**Decisions made:** Chose the Hungarian algorithm to solve frame-to-frame node correspondence as an assignment problem (rather than simple nearest-neighbour matching), and added a Kalman filter per tracked node to smooth position estimates and tolerate a few missed detections before dropping a node.

**Testing notes:** Tested with laptop webcam to ensure it ran without crashing.
