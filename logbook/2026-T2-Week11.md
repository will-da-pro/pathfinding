**Date:** 29 Jun – 3 Jul 2026

**What I worked on:** The biggest week of the project (over 30 commits). Finished making nodes work as ROS2 composable components (constructors take `NodeOptions`, registered via `RCLCPP_COMPONENTS_REGISTER_NODE`, while keeping a standalone `main()` too) and updated the launch file and container setup accordingly. Added "silver" marker detection (a `/silver_present` subscription that moves the state machine to `COMPLETE` and publishes on `rescue_active`), then removed it again two days later. Teammate Bain Changson added green-centroid weighting to the target-point calculation, after which we ran a long joint tuning session on green-marker thresholds, weights, and detection method (pixel count vs. area). Added an `rclcpp_action` client (`MoveTime`) so the robot could execute timed rotate/move-forward manoeuvres at "double green" markers, driven by a small state machine (`TOWER_ROTATE_START/MOVE/END`, `GREEN_ROTATE`, `GREEN_MOVE_FORWARD`). Added, then later removed, `std::chrono`-based timing instrumentation around per-frame processing to diagnose slowness.

**Reflection:** The standout moment was an AI coding assistant had edited `navigation.cpp` without keeping `navigation.hpp` in sync, breaking the build; the compiler error caught it and I fixed the header by hand.

**Decisions made:** Used an action client (goal/feedback/result) for discrete timed manoeuvres at markers rather than streaming `Twist` messages, since "rotate for N seconds" fits a request/result interface better; made green/silver detection thresholds tunable through repeated adjustment rather than fixed constants, given how much lighting varied between test runs.

**Testing notes:** Added temporary wall-clock timing instrumentation (`std::chrono::steady_clock`) around the per-frame processing and threshold steps to check whether the pipeline kept up with the target frame rate, then removed it once satisfied; otherwise tuned thresholds iteratively against live camera footage.

**AI use log:** Used an AI coding assistant at some point this week to help modify `navigation.cpp`. Its edit changed a function without updating the matching declaration in `navigation.hpp`, which broke the build; I caught this from the compiler error and fixed the header myself.
