**Date:** 28–29 Jul 2026

**What I worked on:** Fixed a segfault caused by a raw `TrackedEdge*` pointer (`currentEdge`) being invalidated whenever its backing `vector` reallocated, by switching it to a `std::shared_ptr<TrackedEdge>`. Fixed an indexing bug where a newly-added tracked node was built from the wrong index into the observed-nodes array. Added handling for edges that touch the edge of the camera frame, so direction calculations use the node position rather than indexing into a path array that might be shorter than `minEdgeSize`. Removed leftover debug print statements and added several more recorded test videos aimed at the green-marker detection path.

**Reflection:** The `currentEdge` segfault is a classic "pointer into a vector that later reallocates" bug — since `std::vector` can move its backing storage on growth or erase, any raw pointer taken into it earlier can become dangling; switching to a `shared_ptr` avoids this at the cost of one extra allocation.

**Decisions made:** Chose `shared_ptr` over trying to keep the raw pointer valid some other way (e.g. reserving capacity up front or using indices instead of pointers), prioritising correctness and simplicity since this pointer isn't in a hot inner loop.

**Testing notes:** Added dedicated test videos (`test/green-1.mp4` through `green-4.mp4`) focused specifically on the green-marker detection path, for use with the CTest harness added the previous week.
